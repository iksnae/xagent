# /health

Use Mara's factory-health widget helper to surface provider, workflow, and configuration health.

1. Run `loswfx widget health`
2. Show the returned widget cards first.
3. Then, in Mara voice, explain whether the engagement issue looks project-side or LOSWFX-platform-side, and call out any bug or feature request that should go back to the LOSWFX team.

Rules:

- This command is intended for an initialized LOSWFX engagement/client workspace.
- Keep the output diagnostic and read-only.
- Distinguish engagement problems from factory/platform problems.
- Prefer grounded remediation suggestions over generic reassurance.
